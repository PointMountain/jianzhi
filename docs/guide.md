# 使用指南

[返回 README](../README.md)

## 带来自己的材料

| 入口     | 使用方式                                                                    |
| -------- | --------------------------------------------------------------------------- |
| 本地仓库 | 新建主题 → 本地仓库 → 选择目录 → 预览 → 勾选文件 → 导入。也可粘贴绝对路径。 |
| 文档     | 上传或粘贴 Markdown / TXT，按标题拆分为小节。                               |
| 主题     | 写下想学的主题与目标，让本机 Codex 生成入门路线，边学边核对内容。           |

仓库导入会复制所选 UTF-8 文本，保留本地路径、文件列表和可读取的提交 ID，形成当时的快照。原目录保持只读，不执行其中的源码、脚本或指令。

Git 仓库遵循忽略规则，同时跳过隐藏文件、依赖、产物与符号链接。每次最多导入 50 个文件、总计 2 MB，单文件不超过 256 KB。大目录可选择子目录分批导入。仓库后续变更不会自动同步，仓库图片附件暂不复制。

## 阅读、追问与笔记

在阅读页划选原文后，点击「引用提问」或「记笔记」。右侧会保留摘录，随后可以继续输入自己的问题或解释。摘录最多 3000 字，保存的笔记带有引用与来源小节。

Codex 适合辅助解释概念、给出例子、点评回答。涉及具体事实时请回到原文核对。你也可以先独立阅读和做笔记，只在遇到问题时调用导师。

## 主动回忆与复习

进入「主动回忆」，先写下自己的解释，再提交核对。可以查看原文或请 Codex 点评，最后选择本次自评：

- **还没记住**：次日再练。
- **需要提示**：次日巩固。
- **能独立解释**：到期且跨日时，逐步进入 1、3、7、14、30 天的间隔。

提前或同日的重复练习不跳级；作答前回看材料会按提示后的回忆处理。自评和复习阶段用于安排练习，不是客观记忆率测量。日期按上海时区计算。

计时器只累计页面可见且未暂停的时间，在提交自评时计入历史。未提交的阅读时间不会记入足迹。答案草稿保存在当前浏览器，正式学习记录保存在服务端文件。

## 足迹与总结图卡

- **日历**：切换月份、回到今天、点击日期，回看已保存的回答、笔记和总结。
- **复习安排**：查看到期内容与未来七天的安排，按当前状态筛选。
- **总结画廊**：选择主题与小节，Codex 结合原文、笔记和回答生成结构化总结，排版成可下载的 PNG 图卡。图卡保留来源入口，共学中的 Mermaid 图解也会收录。

图卡是学习信息的可视化排版；README 封面所用的 AI 插画不是应用内的图卡生成功能。

## Codex 与模型选择

「学习设置」展示运行来源、CLI 版本、登录状态与模型。macOS 优先复用桌面应用内置的 Codex，再回退到终端 PATH；可用 `STUDY_CODEX_BIN` 显式指定可执行文件。

| 选择         | 下一次请求如何决定模型                                            |
| ------------ | ----------------------------------------------------------------- |
| CLI 默认     | 优先使用本机模型目录标记的默认模型；无法获取目录时交给 CLI 决定。 |
| 跟随全局模型 | 每次只读取本机 `config.toml` 顶层的 `model` 名称。                |
| 指定模型     | 从本机 `model/list` 返回的目录选择，也可以手动填写模型 ID。       |

选择保存在渐知的学习空间中，不修改全局配置。桌面聊天中的临时选择不会自动同步；跟随全局时只继承模型名称，不继承接口地址或插件配置。是否可用以当前 CLI、账号权限与实际请求为准。

后端调用 `codex exec`，复用本机登录。推理使用在线服务及账号额度，应用没有 API Key 配置页面。请求在临时目录中以只读沙箱运行，忽略用户配置并关闭 shell、浏览器、插件、应用、hooks、记忆和子 Agent，导入材料作为数据处理。

同一时间只运行一个请求，单次最多三分钟，页面支持取消。不完整的回答或总结不会作为成功结果保存。登录异常时可在终端运行 `codex login status`，必要时重新 `codex login`。

## 数据与迁移

默认学习空间为应用目录旁的 `../学习空间/`，由程序位置决定，不受启动命令所在目录影响。「学习设置」显示实际路径。

`study.json` 是权威状态，包含小节正文、回答、自评、复习计划、笔记、对话、总结和模型选择。保存采用临时文件原子替换，已有版本 1 数据会保留。

每个主题自动创建 `source/`、`context/` 与 `exercises/` 目录，用于原始资料、学习背景与练习。普通导入的正文存入 JSON，不自动复制整个仓库到 `source/`。

`exports/learning-notes.md` 在启动和保存后自动更新，便于本机 AI 工具或其他编辑器读取。学习记录应通过网页或本地 API 更新；不要在服务运行期间直接修改 JSON 或 Markdown 镜像。

### 完整备份与恢复

1. 停止渐知服务。
2. 复制整个学习空间目录，包含 JSON、附件、练习和上下文。
3. 恢复前先备份当前目录，再放入需要恢复的文件并重新启动。

设置页的 JSON / Markdown 导出适合携带结构化记录；它们不包含所有外部附件、练习与会话文件。

### 指定其他位置

```bash
STUDY_DATA_DIR=/absolute/path/to/my-study pnpm dev
```

变量必须是绝对路径。迁移时先停服，移动完整目录，再以新路径启动。同一学习空间只运行一个服务。

如果默认启动发现旧版 `.data/study.json`，会提示迁移。可先将 `STUDY_DATA_DIR` 指向旧目录的绝对路径继续使用；新旧两边都有数据时，应分别备份，不要直接覆盖合并。

## 常见问题

**打开后书架是空的？** 新安装从空书架开始。如果已有记录，请在设置页确认当前学习空间路径。

**端口已占用？** 开发模式使用 5188（网页）与 5189（API）。先停止旧实例，再重新运行；不要让多个服务写入同一份学习记录。

**模型不可用？** 查看设置页的 CLI 来源、版本、登录状态。某些模型需要更新 CLI 或具备相应账号权限，可以先切回「CLI 默认」。

**能部署为多人网站吗？** 当前面向本机单人使用，只监听 `127.0.0.1`，并校验 Host / Origin。没有账号体系或多设备同步，请保持本机运行。
