# 使用指南

[返回 README](../README.md)

## 带来自己的材料

| 入口     | 使用方式                                                                    |
| -------- | --------------------------------------------------------------------------- |
| 本地仓库 | 添加主题 → 本地仓库 → 选择目录 → 预览 → 勾选文件 → 导入。也可粘贴绝对路径。 |
| 文档     | 上传或粘贴 Markdown / TXT，按标题拆分为小节。                               |
| 主题     | 写下想学的主题与目标，让本机 Codex 生成入门路线，边学边核对内容。           |

仓库导入会复制所选 UTF-8 文本，保留本地路径、文件列表和可读取的提交 ID，形成当时的快照。原目录保持只读，不执行其中的源码、脚本或指令。

Git 仓库遵循忽略规则，同时跳过隐藏文件、依赖、产物与符号链接。每次最多导入 50 个文件、总计 2 MB，单文件不超过 256 KB。大目录可选择子目录分批导入。仓库后续变更不会自动同步，仓库图片附件暂不复制。

## 阅读、追问与笔记

在原文中划选文字后，点击「引用提问」或「记笔记」。辅助面板会保留摘录，随后可以继续输入自己的问题或解释。摘录最多 3000 字，保存的笔记带有引用与来源小节。

Codex 适合辅助解释概念、给出例子、点评回答。涉及具体事实时请回到原文核对。你也可以先独立阅读和做笔记，只在遇到问题时调用导师。

顶部「章节」打开目录，笔记图标打开提问与笔记面板；关闭后保留草稿并恢复焦点。「专注阅读」收起导航与导师，退出后回到原问题，保留阅读位置与回答。窄屏的「展开全文」也沿用这一规则。Esc 先关闭内部弹层，再退出专注。点击流程图或图片仍可打开预览、缩放；删除笔记需要确认。

## 导师带学

新小节默认进入「导师带学」，点击「开始这一节的带学」才会发起请求。返回已打开的小节时恢复上次模式；「今日」的继续学习会回到最近的小节。可以先填写熟悉的知识或想借助的例子，导师会围绕当前材料，一次提出一个情境问题。

桌面原文与导师各自滚动，新回复通过「有新内容」提示，不打断阅读；窄屏可展开此前讨论或全文。切换到「自主阅读」保留带学回答。「后续学习」中可以选择变式、实作和本轮整理。

1. 写出判断和理由，提交后获得针对回答的反馈。卡住时选择「给一点提示」；反复卡住会转为补讲，也可以直接选择「直接讲解」。
2. 用「换个情境验证」检验迁移应用。每道新题分别记录提示、讲解、原文参考与核对反馈，上一题的提示不会自动算到新题上。
3. 想复核导师的判断，在输入框写下理由，选择「这是追问或纠正」。追问与实际作答分开保存。
4. 到了适合实践的节点，选择「安排一个小实作」。下载包含任务、骨架与验收要求的 Markdown，在自己的编辑器完成，再提交核心实现、运行结果和设计理由。平台不会执行提交的代码；运行证据由你提供。
5. 点击「结束并整理本轮」，查看回答、提示记录、缺口与下一步建议。在「足迹 → 带学记录」可以回看完整过程，未结束的带学也可以从原问题继续。

实际提交先保存，再等待导师回应；中断或返回格式异常时，用「重试本轮」接续，不会重复记录同一份提交。未提交草稿保留在当前浏览器。结束整理不额外调用模型，也不会自动标记掌握或改变复习自评。你始终可以看原文、换题或进入下一节。

带学内容随 JSON 和 Markdown 一起导出，兼容原有版本 1 学习空间。模型沿用学习设置，只在你主动开始或请求下一步教学时调用。

## 主动回忆与复习

进入「主动回忆」，先写下自己的解释，再提交核对。Codex 结合本节题目、材料和你的回答，逐点说明正确处、缺口、参考解释与追问；原文可按需展开。核对失败时保留回答，可以重试或自行记录结果。最后评价核对前的回答：

- **还没记住**：仍讲不清，次日再练。
- **提示后能解释**：借助提示才想起，次日巩固；与“还没记住”保存为不同结果。
- **独立解释**：没用提示，到期且跨日时逐步进入 1、3、7、14、30 天的间隔。作答前看过提示时此项不可选。

选择自评后，点击「保存本次结果」才会保存回答与安排复习；保存失败保留选择和解释。提前或同日的重复练习不跳级；作答前回看材料会按提示后的回忆处理。自评和复习阶段用于安排练习，不是客观记忆率测量。日期按上海时区计算。

点击顶部或正文末尾的「学完本节」会记录完成状态并显示在路线、书架和足迹中。完成一次回忆自评也会标记学完。学完不等于已经掌握，只有提交回忆自评才会安排复习。

计时器只累计页面可见且未暂停的时间，在提交自评时计入历史；单独标记学完不累计阅读时长。未提交的回答、提问与笔记草稿，以及模式和位置，按学习空间和小节保存在当前浏览器；清理浏览器数据会清理这些草稿，JSON 备份不包含它们。正式学习记录保存在服务端文件。核对反馈随自评一起保存，之后可在足迹中展开查看。

## 足迹与总结图卡

- **日历**：切换月份、回到今天、点击日期，回看学完的小节、回答与核对反馈、笔记和总结。
- **复习安排**：查看到期内容与未来七天的安排，按当前状态筛选。
- **总结画廊**：选择主题与小节，Codex 结合原文、笔记和回答生成结构化总结，排版成可下载的 PNG 图卡。图卡保留来源入口，共学中的 Mermaid 图解也会收录。

图卡是学习信息的可视化排版；README 封面所用的 AI 插画不是应用内的图卡生成功能。

## Codex 与模型选择

「学习设置」展示运行来源、CLI 版本、登录状态与模型。macOS 优先复用桌面应用内置的 Codex，再回退到终端 PATH；可用 `STUDY_CODEX_BIN` 显式指定可执行文件。

学习页右侧的模型快捷入口可以切换模型、推理强度（Effort）和 Fast。可选档位来自本机模型目录；Fast 可能消耗更多额度。切换模型会重置为默认强度并关闭 Fast，保存后对下一次讲解、答案核对、课程生成和总结请求生效。

| 选择         | 下一次请求如何决定模型                                            |
| ------------ | ----------------------------------------------------------------- |
| CLI 默认     | 优先使用本机模型目录标记的默认模型；无法获取目录时交给 CLI 决定。 |
| 跟随全局模型 | 每次只读取本机 `config.toml` 顶层的 `model` 名称。                |
| 指定模型     | 从本机 `model/list` 返回的目录选择，也可以手动填写模型 ID。       |

选择保存在渐知的学习空间中，不修改全局配置。桌面聊天中的临时选择不会自动同步；跟随全局时只继承模型名称，不继承接口地址或插件配置。是否可用以当前 CLI、账号权限与实际请求为准。

后端调用 `codex exec`，复用本机登录。推理使用在线服务及账号额度，应用没有 API Key 配置页面。请求在临时目录中以只读沙箱运行，忽略用户配置并关闭 shell、浏览器、插件、应用、hooks、记忆和子 Agent，导入材料作为数据处理。

同一时间只运行一个请求，单次最多三分钟，页面支持取消。不完整的回答或总结不会作为成功结果保存。登录异常时可在终端运行 `codex login status`，必要时重新 `codex login`。

## 数据与迁移

默认学习空间为应用目录旁的 `../学习空间/`，由程序位置决定，不受启动命令所在目录影响。「学习设置」显示实际路径。

`study.json` 是权威状态，包含小节正文、完成状态、回答与核对反馈、自评、复习计划、笔记、对话、总结和请求设置。保存采用临时文件原子替换，已有版本 1 数据会保留；旧版已练习的小节按首次回忆日期显示为已学完。

每个主题自动创建 `source/`、`context/` 与 `exercises/` 目录，用于原始资料、学习背景与练习。普通导入的正文存入 JSON，不自动复制整个仓库到 `source/`。

`exports/learning-notes.md` 在启动和保存后自动更新，便于本机 AI 工具或其他编辑器读取。学习记录应通过网页或本地 API 更新；不要在服务运行期间直接修改 JSON 或 Markdown 镜像。

### 完整备份与恢复

1. 停止渐知服务。
2. 复制整个学习空间目录，包含 JSON、附件、练习和上下文。
3. 恢复前先备份当前目录，再放入需要恢复的文件并重新启动。

设置页的 JSON / Markdown 导出适合携带结构化记录；它们不包含所有外部附件、练习与会话文件。

### 指定其他位置

```bash
STUDY_DATA_DIR=/absolute/path/to/my-study pnpm dev
```

变量必须是绝对路径。迁移时先停服，移动完整目录，再以新路径启动。同一学习空间只运行一个服务。

如果默认启动发现旧版 `.data/study.json`，会提示迁移。可先将 `STUDY_DATA_DIR` 指向旧目录的绝对路径继续使用；新旧两边都有数据时，应分别备份，不要直接覆盖合并。

## 常见问题

**打开后书架是空的？** 新安装从空书架开始。如果已有记录，请在设置页确认当前学习空间路径。

**端口已占用？** 开发模式使用 5188（网页）与 5189（API）。先停止旧实例，再重新运行；不要让多个服务写入同一份学习记录。

**模型不可用？** 查看设置页的 CLI 来源、版本、登录状态。某些模型需要更新 CLI 或具备相应账号权限，可以先切回「CLI 默认」。

**能部署为多人网站吗？** 当前面向本机单人使用，只监听 `127.0.0.1`，并校验 Host / Origin。没有账号体系或多设备同步，请保持本机运行。
