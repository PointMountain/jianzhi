## 原型结论

原型保存在 sibling worktree `../jianzhi--a2-interaction-prototype`，分支 `a2-interaction-prototype`，提交 `6aa83e8`。直接打开 `src/learning-flow.prototype.html` 即可运行。它使用内存示例，不连接服务，不代表真实导师验收。

- 学习模式属于小节；专注阅读是显示状态。进入和退出专注不结束带学请求。
- 回答草稿按学习空间、主题、小节隔离；切换模式不卸载带学组件。
- 原文和导师独立滚动。新回复显示入口，由学习者主动回到最新。
- 请求结果属于发起的小节；离开后旧页面不得覆盖新页面。
- 主动回忆中查看材料记为提示；学完不虚构掌握证据。

浏览器自由操作验证了草稿跨小节恢复、Esc 退出专注、材料辅助限制；原型场景还保留了请求竞态与完成语义供复核。

## 实现约定

1. `study.json` 保持版本 1，记录与导师会话继续由原有服务负责；新增可选 revision 与保存凭据，缺省兼容旧数据，本轮不迁移正式数据。
2. 浏览器的模式、阅读和导师滚动位置、各类未提交草稿以结构化的 `[storagePath, courseId, lessonId]` 为键存放在 localStorage。它们是本浏览器的恢复信息，JSON 备份不包含这些草稿；清理浏览器数据会清理草稿。旧版无空间标识的草稿只迁入第一个认领它的学习空间，原值仍保留。
3. URL 显式的 `?read`、`?guided`、`?recall` 优先，其次恢复小节模式，初次默认导师带学。今日和课程详情共用最近小节记录。
4. 双栏在可用宽度不足时变为原文摘要与导师单列。展开全文沿用专注视图；退出回到同一问题、草稿和导师滚动位置。
5. 章节、提问与笔记复用现有焦点受限弹窗；Esc 先关闭弹窗，再退出专注。划选工具继续依附稳定的 Markdown 节点。
6. 回忆自评先选结果，再保存；保存失败保留选择和解释，成功日期来自服务。
7. 添加主题为独立页面，三种方式共享入口，各自保留输入。导入仍使用原服务限制，源目录只读。
8. 全局采用 `paper.css` 中的 A2 语义色与几何规则，沿用共享控件，保留深色、键盘和减少动效支持。
9. 创建主题、导入、笔记与回忆保存使用请求凭据。未知结果先读回已保存状态再重试；凭据与记录原子写入，服务重启后仍可去重。较旧的状态响应不能覆盖新状态。

## 验收中发现并修正

- 同一小节只改变 URL 查询参数时没有更新模式：增加对当前小节显式模式的监听。
- 窄屏仍继承旧网格页头，且历史对话挤占首屏：改为紧凑页头，窄屏按需展开此前讨论。
- 窄屏章节按钮宽度只有 40px：修正为至少 44px，复测受影响的六组页面。
- 保存导师回复会清空另一份笔记草稿：只在真正保存当前草稿时清空。
- 添加主题移为常驻页面后，离开页面仍可能接收旧生成结果：关闭时取消对应请求；仓库导入离开当前方式后也取消在途操作。

临时环境的接线问题（代理来源端口、测试桩执行权限）已在隔离环境修正，没有改动应用访问限制。空空间验收同样通过独立 Vite 代理，避免非默认端口下带 Origin 的静态资源被既有校验拒绝。首次渲染回归期间出现一次滚动引起的工具栏关闭；当时有样式热更新，未确认它是唯一原因。停止修改后重新运行，九项全部通过，无节点移除或意外滚动。
