## 已确认的体验

1. 新小节默认导师带学；返回已有小节时恢复上次模式和进度。
2. 今日的首要行动是继续上次学习，到期复习提供明显的次要入口。
3. 导师带学、自主阅读都是完整模式；共享材料与笔记，保留各自草稿。
4. 桌面带学左侧常驻原文、右侧呈现导师；两栏独立滚动，章节和笔记按需展开。窄屏保留原文摘要，展开全文后返回原问题。
5. 学习完成与掌握证据分开；导师核对针对问题和用户回答。
6. 全站采用一致控件、焦点、忙碌态、失败恢复与保存反馈。
7. 侧栏底部、设置上方的“添加主题”是低频全局操作入口；独立页面内整合从主题开始、导入材料与本地仓库。

## 关键交互约定

### 学习模式与恢复

恢复状态按主题和小节隔离，包含上次模式、阅读位置、带学阶段、未提交回答、提问与笔记草稿。初次进入使用导师带学；只切换模式不能触发“学完”或重建会话。先加载已有状态，再显示模式，避免阅读与带学闪切。今日和书架的“继续”必须恢复同一份最近学习记录。

桌面带学的原文和导师各自滚动，导师产生新回复不改变阅读位置。章节和笔记按需展开，关闭后恢复触发处的焦点。窄屏带学保留原文摘要；展开全文不会切换学习模式，返回后仍是同一道题和同一份回答草稿。媒体预览继续使用可关闭面板。学习模式切换保留双方输入，且不能因组件卸载丢失草稿。生成期间，简单查看材料可以继续；会切换请求上下文的操作应明确停止或等待，不能让旧请求覆盖新小节。

### 请求、流式内容与取消

同一个任务避免重复提交。每轮请求与发起的小节、会话、提交内容绑定；过期回调不能更新当前页面。停止后保留输入和已收到的片段，明确其未完成状态。网络中断时不把结果未知当作已取消或成功；先核对已保存结果，再允许可能重复写入的重试。

用户查看较早内容时，新回复不能强制滚到最底；显示“有新内容”，由用户回到最新。页面加载期间不先展示空书架。错误只替换受影响的区域，不清空已加载材料。

### 主动回忆、自评与学完

提交解释后核对当前问题与回答；反馈不是自动判定掌握。自评保留 `again`、`hint`、`good` 三类语义：还没记住、提示后能解释、独立解释。作答前使用提示、材料或旧对话后，禁用独立解释并说明原因。修改解释继续按提示后作答处理。

设计将选择结果和保存分成两步：先选自评，再“保存本次结果”。保存中防止重复点击，失败保留选择和解释；服务确认后显示实际下次复习日期。此处是相对当前实现的行为调整，应在后续规格单独列验收。不得将设计示例日期硬编码进应用。

“学完本节”独立保存完成状态，不虚构回忆记录。当前兼容逻辑允许已有复习记录推导完成状态；重构不得清除这些历史记录。完成后提供主动回忆、下一小节和结束，避免只有单一强迫路径。

### 新建、导入与保存

侧栏底部、设置上方的低频操作组提供“添加主题”操作，打开独立页面；页面内部提供“从主题开始 / 导入材料 / 本地仓库”三种方式，不把三种方式分别加进全局导航。切换方式保留各自输入。字段校验就地显示，提交失败、停止和读取失败都保留内容。进入生成路线后先检查结果，再开始学习。创建请求结果未知时先刷新书架核对，避免重复主题。

文本导入保留来源链接这一现有可选字段；主稿未展开全部可选字段，实现不能因此删除它。Markdown / 文本最大 500 KB；仓库导入最多 50 文件、合计 2 MB、单文件 256 KB，隐藏文件、依赖、产物和符号链接跳过，限制仍由现有服务校验。源目录只读，不运行脚本与安装。

笔记只有收到保存成功结果后才显示“已保存”。删除弹窗标出笔记对象，取消不修改数据，失败保留原笔记。设置的模型和能力以本机返回为准；切换模型重置不兼容的 Effort/Fast，只影响渐知的新请求。

Markdown 用于阅读，JSON 是结构化记录备份；迁移所有材料与练习需复制整个学习空间。应用不存在一键打包完整空间能力，设计不声称已具备。

### 响应式、键盘与辅助功能

窄屏采用单列，带学顶部常驻材料摘要，可展开全文并返回原问题；辅助面板和全局导航按需打开，关闭回到原任务。1024px 带学稿保留约 500px 原文与 360px 导师区；更窄时按内容最小宽度切换为单列。内容宽度决定折叠，不把正文挤成窄列；表格与代码独立横向滚动。设计示例为 1440、1024、390px，实现需要额外验证常见桌面宽度及长中文内容。

共享选择器支持方向键、Home/End、Enter/Esc；模式开关支持键盘与可读选中状态。弹窗限制焦点并在关闭后恢复，按钮可见焦点、高对比状态和触控区域统一。忙碌区域用 aria-busy，结果与错误提供适当通知。减少动效偏好关闭非必要过渡；静态稿不证明这些已生效。

### 阅读密度与专注视图

学习工作区收紧为 16px 纵向、24px 横向边距，12px 页头间隔、20px 双栏间隔。正文 16px / 1.75 行高、12px 段间隔；普通纸面内边距为 20px。用包含多个小标题、代码与完整解释的长章节检验首屏密度，长内容在正文视口滚动，不用大量弹性留白撑满页面。当前问题、输入和提交操作保持可见，历史内容可继续滚动；1024px 默认只显示最近一轮前文摘要。

“专注阅读”是显示状态，不是第三种学习模式。从带学进入时，隐藏导航、导师和模式栏，保留退出、章节、字号与阅读进度；正文最大约 980px，避免过长行宽。退出恢复原模式、原问题、导师位置和未提交回答，材料位置采用此次实际读到的位置。导师仍在生成时可以专注阅读，返回后显示新内容提示，不抢阅读滚动。退出按钮始终可见，Esc 先关闭内部弹层，再退出专注。窄屏展开全文采用同样的连续性规则。主动回忆的材料辅助规则保持独立，不通过专注阅读绕过。

## 本轮检查与边界

- Pen 内检查 38 个根画板及展开组件；允许 0.5px 浮点舍入，未发现意外超出容器边界的项。10 个明确标记的阅读滚动视口有意裁切长章节，单列记录，静态裁切不代表滚动已经实现。
- 1,370 段可解析实色前景及背景的文本，最低对比度约 4.57:1；未发现低于普通文本 4.5:1 或大字 3:1 的项。此检查不涵盖未来运行时的图像背景与全部交互状态。
- 查看了桌面、窄屏、深色、导入、反馈与状态板代表渲染；统一示例主题和进度，纠正备份文案。
- 6 个 Pen clipping 标记源于浮点边界舍入，超过父边界的数值小于 0.5px，已单列在 JSON 结果中，没有当作真实溢出。
- 评审与文档整理按仓库要求在主线程顺序进行，没有独立子代理评审。详见 [评审记录](review.md)。
- 未修改应用源码、服务或正式学习记录。本轮不运行应用行为测试，不把静态稿当作浏览器验收。
