## Standards

按仓库的工具映射，在主线程顺序评审，没有独立子代理评审。检查数据边界、版本兼容、共享控件、领域术语及维护成本。

- 已修正：散落的恢复信息归入浏览器状态模块；最近记录使用结构化键，避免路径与 ID 拼接碰撞；旧草稿只归属第一个认领它的空间，不跨空间重复迁入。
- 已修正：把今日页面提取为独立组件，去掉旧封面、学习循环及未用导入，避免在主路由中保留两套界面。
- 已修正：保存请求凭据与业务记录一起原子写入；状态递增版本防止晚到响应回滚 UI。兼容没有这些可选字段的版本 1 数据，没有删除、重写或迁移历史业务记录。
- 已修正：可点击的日历日期不再通过透明度变成低对比文字。
- 设计检测器仅报告紧凑字号未出现在 frontmatter 排版表的建议项；具体用途已在 DESIGN.md 说明。其余机械项未报告问题；此结果不等于完整可访问性认证。

本轮发现的阻断问题已修复。保留既有 Mermaid 大资源块构建提示，不改变图表功能或伪称其已优化。

## Spec

- 已修正：今日旧书封 / 周统计布局与 A2 不一致；书架继续按钮此前只打开详情；笔记原来仍是卡片网格。
- 已修正：长讨论把作答区推离首屏；经实际使用反馈再次调整为导师整栏单一滚动，各尺寸均按需打开完整讨论，当前问题完整展开，提供直接定位作答入口。
- 已修正：学完后只有 toast；现在有回忆、下一节和结束出口，且没有新增回忆或掌握记录。
- 已修正：网络中断后重复保存风险；主题、导入、笔记与回忆使用稳定凭据并先核对结果，API 拒绝凭据被用于不同内容。
- 已修正：常驻创建页面收到已退出请求的回调；切换页面或方式会停止对应请求。

本轮要求均有实现对应或继承的已验证行为。38 张稿是页面与状态设计，运行界面采用真实内容和流动尺寸，不声称截图逐像素相同。原有接口交付完整响应，没有新增 token 流；停止时保留已经提交或收到的内容，不展示虚假的生成片段。

## 可复跑入口

先在独立绝对路径 `STUDY_DATA_DIR` 启动服务，并核对 `/api/bootstrap.storagePath`。布局 / 渲染脚本使用带两张 Mermaid 的小节 URL。连续性 / 请求脚本要求确定性 fixture，启动时设置 `STUDY_CODEX_BIN` 指向 `server/fixtures/guided-codex.cjs` 的可执行包装，`GUIDED_FIXTURE_MODE=$STUDY_DATA_DIR/mode`；不要用真实 CLI 跑故障脚本。

```sh
corepack pnpm@10.17.1 test
corepack pnpm@10.17.1 build
JIANZHI_CHECK_URL="$ISOLATED_LESSON_URL" node scripts/check-a2-layout.mjs
JIANZHI_CHECK_URL="$ISOLATED_BASE_URL" node scripts/check-a2-flow.mjs
JIANZHI_CHECK_URL="$ISOLATED_LESSON_URL" node scripts/check-a2-requests.mjs
JIANZHI_CHECK_URL="$ISOLATED_LESSON_URL" node scripts/check-learning-render.mjs
```

上述脚本同时读取导出的 `STUDY_DATA_DIR`；可设置 `JIANZHI_CHECK_SPACE` 复用同一 ego-browser TaskSpace。请求脚本的小节必须有带学会话和第二小节，可使用 flow 脚本刚创建的主题。原始结果写入忽略目录 `artifacts/a2/`，结构化结论随本文件交付。测试桩证明状态行为；真实 Codex 两回合的独立证据见 `implementation.md`。
