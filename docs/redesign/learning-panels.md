# 学习面板：实际使用反馈修正

2026-10-04，接续 A2 交付。用户截图指出提问弹窗空白过大、导师区嵌套滚动、内容重复和操作间距失衡。

## 原因与调整

- 导师整栏、历史回复、当前问题分别滚动；同一道问题同时出现在回复与作答区。现在只保留整栏滚动，本次讲解和作答连续排列，当前问题只出现一次；完整历史通过一个入口查看，记录没有删除。
- 提问弹窗沿用了旧侧栏的固定高度和重复标题。现在工具栏只保留模式与一份模型设置，空对话按内容高度展开，输入框从两行起步。长对话只在消息区滚动，低高度窗口统一使用弹窗主体滚动。
- 空对话也执行滚到底部，导致欢迎内容被截掉。自动滚动现在仅处理真实消息。
- 引用预览压缩为两行，完整原文始终可打开查看，输入与保存仍使用完整引用。
- 旧样式的 `min-height: 100dvh` 和 `min-height: 500px` 覆盖了窄屏可用高度，引入页面与内容区双重滚动。学习容器现在允许按视口收缩；长讲解提供“去作答”入口。
- 后续变式、实作与整理默认折叠；保持当前回答优先，保留停止、重试、专注阅读和历史讨论入口。

使用独立空间 `/tmp/jianzhi-a2-layout.jwrgn4m9`，先核对 `/api/bootstrap.storagePath`，通过 API 创建示例。导师与长对话使用临时确定性 CLI 测试桩，证明界面与状态行为，不代表本轮重新验证了真实模型质量。

19 项单元/API 测试与生产构建通过。连续性脚本新增问题去重、导师内容无嵌套滚动、空对话不截断三个断言，共 21 项通过；请求停止、重试与跨小节取消 6 项通过；计时、图表、选区和输入节点稳定性 9 项通过。复跑入口为 `scripts/check-a2-flow.mjs`、`scripts/check-a2-requests.mjs` 和 `scripts/check-learning-render.mjs`，均需独立空间与对应测试桩。

首次渲染检查遇到一次阅读区滚动导致工具栏关闭，没有图表节点重建；显式进入自主阅读后复测九项通过，未确认首次滚动的唯一原因。渲染脚本改用显式阅读入口，避免把模式恢复和渲染稳定性混在同一次测量中。请求检查的同名标题/按钮选择器，以及引用弹层 Escape 的非焦点目标，均为测试脚本问题，已改为明确的按钮/键盘操作。
