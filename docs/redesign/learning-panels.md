# 学习面板：实际使用反馈修正

2026-10-04，接续 A2 交付。用户截图指出提问弹窗空白过大、导师区嵌套滚动、内容重复和操作间距失衡。

## 原因与调整

- 导师整栏、历史回复、当前问题分别滚动；同一道问题同时出现在回复与作答区。现在只保留整栏滚动，本次讲解和作答连续排列，当前问题只出现一次；完整历史通过一个入口查看，记录没有删除。
- 提问弹窗沿用了旧侧栏的固定高度和重复标题。现在工具栏只保留模式与一份模型设置，空对话按内容高度展开，输入框从两行起步。长对话只在消息区滚动，低高度窗口统一使用弹窗主体滚动。
- 空对话也执行滚到底部，导致欢迎内容被截掉。自动滚动现在仅处理真实消息。
- 引用预览压缩为两行，完整原文始终可打开查看，输入与保存仍使用完整引用。
- 旧样式的 `min-height: 100dvh` 和 `min-height: 500px` 覆盖了窄屏可用高度，引入页面与内容区双重滚动。学习容器现在允许按视口收缩；长讲解提供“去作答”入口。
- 后续变式、实作与整理默认折叠；保持当前回答优先，保留停止、重试、专注阅读和历史讨论入口。
