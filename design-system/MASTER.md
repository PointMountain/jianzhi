# 渐知 · 交互与视觉规范

适用范围：今日、书架、课程详情、知识路线、复习、笔记、足迹日历、总结画廊、学习页、设置，以及所有创建和导入弹窗。

## 方向

保留暖纸色、棕色重点和宋体标题，正文使用本机无衬线字体。学习内容优先，以留白、字号和分组建立层次，不增加装饰动画或远程字体。浅色与深色共用语义 token。

本轮使用 ui-ux-pro-max 的 design-system 与 UX 检索；采用其一致性、键盘访问、加载反馈和移动布局原则。项目实际为 React Web，继续使用现有 React、Phosphor 和 Radix 技术栈。

## 单一实现入口

- `src/Controls.tsx`：SelectField、Segmented、Disclosure。所有下拉选择、分段筛选与折叠内容复用这些组件。
- `src/Modal.tsx`：弹窗标题、说明、关闭入口、滚动区域、焦点恢复。
- `src/controls.css`：共用交互层；排在现有页面布局层后，对共用控件保持最终样式约束。
- `src/styles.css`：页面结构与内容布局。不要在页面里另外定义缩小的按钮、下拉菜单或弹窗。

## 尺寸与状态

采用 4 / 8 / 12 / 16 / 24 / 32px 间距；控件间距 8–12px，字段之间 24px，页面分区 32px。

按钮、输入、选项的最小高度为 44px；图标按钮为 44 × 44px。控制圆角 10px、面板 16px、弹窗 20px。主按钮只用于当前操作，其他入口使用描边或轻量按钮。

悬停、按下、选中、键盘焦点、禁用和异步状态需要可区分。交互过渡为 180ms，遵循 reduced-motion。正文辅助色、边框、错误色和弹层背景都使用语义变量。

## 控件约定

- 下拉菜单使用 Radix Select，支持方向键、Home / End、文字定位、Enter 选择、Esc 关闭、长列表滚动；菜单通过 Portal 展示，避免被面板裁剪。空选项提供说明并禁用。
- 分段选择使用有名称的按钮组和 `aria-pressed`，保持正常 Tab 顺序。
- 折叠区使用 button + `aria-expanded` + `aria-controls`，隐藏内容不接收焦点。
- 弹窗标题与关闭入口保持可见，正文独立滚动；点遮罩不丢弃输入，关闭后返回入口焦点。不可取消的保存过程中锁定关闭；可取消的生成流程保留关闭取消能力。
- 表单保留可见标签，错误显示在相关区域，按钮显示处理中状态。上传入口保留真实文件输入与键盘可达性；复选框保留原生语义并统一外观。

## 窄屏与阅读

760px 以下，主导航放在页面顶部，释放正文宽度；六个现有导航入口全部保留。页面左右留白 16–20px，表单文字 16px。日历保留七列，图卡与学习区按内容堆叠。

窄屏学习目录使用同一弹窗，不让目录覆盖正文却仍把焦点留在背景中。长标题允许换行；下拉触发器省略的内容可在菜单中完整阅读。

## 验收边界

所有测试学习记录只进入独立 `STUDY_DATA_DIR`。验收需要覆盖空列表、长标题、下拉键盘操作、弹窗关闭及焦点恢复、笔记保存、回忆自评、深浅主题、375px、平板、桌面、横屏和减少动态效果。
